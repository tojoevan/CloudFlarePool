# 00 · 项目总览与文档规范

> 状态：已定稿 ｜ 最后更新：2026-08-15 ｜ 负责人：家事本开发组
> 适用范围：整合项目（平台核心 + 多端客户端 + 多应用底座）

## 1. 项目定位

本项目是一个**整合型产品**：以「家事本」微信小程序为首个入口，规划覆盖 Web / App / MCP / Skill 等多端，后端共用一套平台级 API。

后端核心（数据湖 `data.kapibala.icu`：Cloudflare Worker + D1 + R2）被刻意设计为 **app-agnostic 多应用平台底座**——家事本只是第一个 `app`，后续应用靠"声明 schema"接入，而非改动数据湖代码。

## 5. 仓库与模块边界

- **`cloudflarepool/`**（平台核心）：本 `docs/` 目录所在地；含数据湖 Worker + D1 + R2、网关 `gateway/`。
- **`jiashiben/`**（小程序前端）：仓库级 `README.md` 为应用入口，不重复本目录讨论资产；其发布/维护流程已分解进 `05-开发指南` / `04-检视` / `06-变更日志`。
- **网关**不独立成仓：Node.js 网关实现在 `cloudflarepool/gateway/`，nginx relay 参考在 `jiashiben/backend/relay/`。
