### 技术变更清单（内部，不进版本说明）

- 设计系统：`app.wxss` 新增 `--space-1..6` + `--page-pad` + `--text-xs..xxl` 共 13 个 token

- 收敛散落魔数（40rpx→`--page-pad`、28rpx→`--text-base` 等）
- 统一 `.empty` 全局空状态类
- 补充 `disabled` / `loading` 组件状态
- 门禁复跑：`lint --strict` + regression 全绿
