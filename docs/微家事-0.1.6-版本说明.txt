微家事 0.1.6 更新内容：
· 修复个人/家庭空间切换后内容未隔离的问题，切换空间后列表与统计现在会正确过滤
· 修复家庭页成员头像底色的显示样式
· 提升各页面渲染稳定性，新增回归测试防止同类问题复发

（注：本版不引入视觉风格大改，沿用现有小程序样式；画布 B 的重设计方案本轮不采用，待稳定运营一段时间后再评估）

【本版技术变更】（内部，不进版本说明）
1. 功能修复
   - 新增 utils/space.js：统一导出 filterBySpace / inSpace，定义家庭空间 = dot==='family' || shared===true
   - pages/today/today.js：onShow / setSpace 接入空间过滤，移除早期误加的 computeSummary
   - pages/archive/archive.js：缓存 _allItems 全量，加载与切换空间后按空间过滤
   - pages/mine/mine.js：todo / archive / record 计数按 inSpace 统计

2. 视觉与样式
   - pages/today/today.wxml：顶部结构重构为 .home-header，移除右上角 favicon（被小程序胶囊遮挡）
   - pages/today/today.wxss（新建）：页面作用域 --brand:#FF7A45 局部换肤，新增 .home-sub 样式
   - app.wxss：补全 --brand-border token，修复 family.wxss 引用未定义变量
   - pages/family/family.wxss：.avatar.family fallback #7BA7BC → #7A8471
   - .sub → .home-sub 重命名，避免与全局/其他页面类名冲突（strict lint 全绿）

3. 测试与门禁
   - scripts/regression-check.mjs 新增 13 条空间过滤功能断言（覆盖 filterBySpace / inSpace 边界）
   - package.json version 0.1.5 → 0.1.6
   - npm run preflight（lint + test）全绿

4. 网关侧配套
   - 服务器 /www/wwwroot/home.inkspcl.com/.env 追加 MINIAPP_VERSION=0.1.6
   - 需宝塔面板重启网关，使版本矩阵读取到 0.1.6
